Referencia de todo lo que hay en la pestaña **Ajustes**, en orden.

| Sección | Opción | Detalle |
|---|---|---|
| **Permisos** | Apple Health | Estado y botón *Conectar* o *Abrir Ajustes*. Muestra errores del sistema. |
| **Sincronización** | Sincronizar ahora (todo) | Sincroniza todo el historial. |
| | Sincronizar rango seleccionado | Aparece si activas el filtro de rango. |
| | Último sync | Hora relativa. |
| | Estado de iCloud | Ver [iCloud](/apps/synctracers/docs/icloud). |
| | Filtrar por rango de fechas | Desactivado. *Desde* y *Hasta*. |
| | Sincronización en background | Solo iOS. Activada. |
| | Intervalo | Solo iOS. 1-24 h, por defecto 6 h. |
| | Descargar entrenamientos anteriores | Añade la frecuencia cardíaca media. Ver [Sincronización](/apps/synctracers/docs/sync). |
| **Exportar** | Exportar y compartir JSON | Solo iOS. |
| **Vault local** | Estado, meses, Refrescar ahora… | Ver [Exportar y Vault](/apps/synctracers/docs/export-vault). |
| **API para Agentes** | Iniciar API local | Solo Mac. |
| **Analíticas** | Compartir uso anónimo | Desactivado por defecto. |
| **Acerca de** | Versión, Modelo de datos | «SwiftData + CloudKit». |

**No hay:** selector de idioma (sigue el del sistema), unidades (siempre km/m y kcal), borrado de datos, tema, notificaciones ni enlace a la política de privacidad.

## Analíticas

El interruptor **Compartir uso anónimo** está desactivado por defecto. Si lo activas, se envían recuentos de uso (cuántas veces sincronizas, qué pantallas abres, si una exportación tuvo éxito). Nunca se envían datos de salud, entrenamientos, rutas ni ubicación. Más detalle en la [política de privacidad](/privacy/synctracers).
