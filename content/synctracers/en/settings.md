A reference for everything in the **Settings** tab, in order.

| Section | Option | Detail |
|---|---|---|
| **Permissions** | Apple Health | Status and *Connect* or *Open Settings* button. Shows system errors. |
| **Sync** | Sync Now (all) | Syncs the whole history. |
| | Sync selected range | Appears if you turn on the range filter. |
| | Last sync | Relative time. |
| | iCloud status | See [iCloud](/apps/synctracers/docs/icloud). |
| | Filter by date range | Off. *From* and *To*. |
| | Background sync | iOS only. On. |
| | Interval | iOS only. 1-24 h, default 6 h. |
| | Download past workouts | Adds average heart rate. See [Syncing](/apps/synctracers/docs/sync). |
| **Export** | Export and Share JSON | iOS only. |
| **Local Vault** | Status, months, Refresh Now… | See [Export and Vault](/apps/synctracers/docs/export-vault). |
| **API for Agents** | Start Local API | Mac only. |
| **Analytics** | Share anonymous usage | Off by default. |
| **About** | Version, Data Model | "SwiftData + CloudKit". |

**Not there:** a language picker (it follows the system), units (always km/m and kcal), data deletion, theme, notifications or a link to the privacy policy.

## Analytics

The **Share anonymous usage** switch is off by default. If you turn it on, usage counts are sent (how often you sync, which screens you open, whether an export succeeded). Health data, workouts, routes and location are never sent. More detail in the [privacy policy](/privacy/synctracers).
