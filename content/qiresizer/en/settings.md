QIResizer has no settings window or preferences menu. The only thing remembered between sessions is the theme.

## Theme

The round button in the top-right corner (tooltip: *Change Theme*) switches theme each time you click it, in this order:

| Icon | Theme |
|---|---|
| Monitor | System (follows macOS appearance) |
| Sun | Light |
| Moon | Dark |

Your choice is saved and kept when you reopen the app. The default is System.

## What isn't remembered

These settings go back to their initial value every time you open the app:

| Setting | Initial value |
|---|---|
| **Size** | 1080p |
| **Lock Aspect Ratio** | On |
| **Format** | JPEG |
| **Quality** | 85% |
| **Custom Name** | Empty |
| Destination folder | Asked every time |

## Language, version and price

- **Language**: the interface is English only; there is no Spanish version.
- **Window**: minimum size 600 × 650.
- **macOS**: 14.0 or later.
- **Price**: according to the project's documentation, it is free with no in-app purchases.

## Privacy and permissions

QIResizer contains no analytics or networking code: everything is processed locally and your images are never sent anywhere. It uses the macOS sandbox with a single permission, read and write access to the files and folders you select. See the [privacy policy](/privacy).
