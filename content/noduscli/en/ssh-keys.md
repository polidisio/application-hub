Besides a password, you can sign in with a private key. NodusCli stores **one single key** and uses it for all your servers.

## Supported formats

| Format | Supported? |
|---|---|
| OpenSSH ed25519 (`BEGIN OPENSSH PRIVATE KEY`), no passphrase | Yes |
| ECDSA P-256, P-384 or P-521 in PEM, no passphrase | Yes |
| ECDSA in OpenSSH format (`BEGIN OPENSSH PRIVATE KEY`) | No |
| RSA | No |
| Any passphrase-protected key | No |
| PuTTY `.ppk` | No |

> ECDSA keys generated by `ssh-keygen` by default use the OpenSSH format, which the app rejects (*Key type … not supported. Use ed25519.*). For ECDSA you need a PEM key. The simplest path is to generate an ed25519 key: `ssh-keygen -t ed25519`.

## Importing a key

1. On the main screen, in the **SSH key** section, tap **Import private key…**.
2. Pick the private key file in the iOS file picker (Files, iCloud Drive, etc.).
3. The app validates the key **before** saving it. If it's valid, the section shows **Key stored in Keychain**.

If something is wrong you'll see the **Cannot import key** alert with the reason, and nothing is saved:

| Message | What to do |
|---|---|
| *RSA keys are not supported. Use ed25519 or ECDSA.* | Generate an ed25519 key. |
| *.ppk not supported. Export with puttygen…* | In PuTTYgen: Conversions > Export OpenSSH key (new format). |
| *Passphrase-protected keys are not supported yet…* | Remove the passphrase: `ssh-keygen -p -N "" -f <key>`. |
| *Key type … not supported. Use ed25519.* | It's an OpenSSH key that isn't ed25519. Use ed25519 or export the ECDSA key as PEM. |
| *Unrecognized private key format.* | The file isn't a supported private key. |
| *Corrupt key.* | The file is damaged or incomplete. |

> Removing a passphrase leaves the key unprotected in the original file. Do it on a copy and delete it after importing.

## Using the key on the server

Add the **public** key (`.pub`) to the server's `~/.ssh/authorized_keys`. In the server form you can leave **Password** empty. If the server doesn't accept public-key auth and no password is saved, the attempt fails (see [Troubleshooting](/apps/noduscli/docs/faq)).

## Removing the key

In **SSH key**, tap **Remove key**. It's deleted from the Keychain immediately, without confirmation. To replace it, remove it and import another: you can't import a second one while one is stored.

## Where it's stored

Only in the Apple Keychain, readable only while the device is unlocked and never leaving this device. Never in preferences or iCloud. See [Data and privacy](/apps/noduscli/docs/data-privacy).
