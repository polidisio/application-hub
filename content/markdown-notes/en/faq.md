## I cannot find Settings

They are under the gear in the editor header, so open a note first. See [Settings](/apps/markdown-notes/docs/settings).

## I exported to DOCX and it will not open

This is a current limitation: DOCX export does not produce a valid document. Use **PDF**, **HTML** or **Markdown**. See [Import and export](/apps/markdown-notes/docs/import-export).

## "Export all notes" does nothing

True: right now it closes the sheet without generating a file. Export note by note.

## The Markdown + HTML/Texto ZIP will not open

Those ZIPs are built in a basic way and may come out corrupted. Export **Markdown** and **HTML** (or **Texto**) separately.

## I imported a file and no note appeared

Only `.md`, `.markdown` and `.txt` files are accepted, one at a time, in UTF-8. Any other case fails silently. Try copying the file to **On My iPhone** and importing again.

## I deleted a note by accident

There is no trash or undo. If you use iCloud, the deletion has already spread. For important notes, export to **Markdown** first.

## I cannot search by tag

Search only looks at title and text, and there is no tag filter. See [Folders, tags and search](/apps/markdown-notes/docs/organize).

## Search does not find a note I know exists

If a folder is selected, search only looks inside it. Tap **All Notes** and try again.

## I typed in "Editable Text" and my table or list changed

The formatted view is converted back to Markdown approximately. Edit in **Edit** or **Split** when you use tables, numbered lists or advanced syntax. See [The editor](/apps/markdown-notes/docs/editor).

## `- [ ]` checkboxes or `~~strikethrough~~` show without formatting

The app's Markdown engine does not turn them into their own formatting. See [Markdown syntax](/apps/markdown-notes/docs/markdown-syntax).

## It does not sync with my other device

Check that both use the same iCloud account, that iCloud is on for Markdown Notes in iOS settings, and that you are online. The app does not show sync status. See [Data and sync](/apps/markdown-notes/docs/data-sync).

## My theme or accent colour did not carry over to the other device

That is normal: those settings are stored per device.

## I see some text in Spanish although my iPhone is in English

Some texts are fixed in Spanish (for example **Notas**, **Buscar notas**, **Eliminar**, **Cancelar**, **Cerrar**). This is a limitation of the current version.

## Does it have focus mode, templates or keyboard shortcuts?

No. There is also no trash, pinned notes or tag search.

## Does it work on iPad and Mac?

It works on iPhone and iPad (iOS/iPadOS 17.0 or later). The app is set up to run on Apple-silicon Macs as an iPad app, but it is not a native Mac app.

## What data does the app collect?

The app has no analytics or ads. Your notes only leave the device for your iCloud, if you have it. See the [privacy policy](/privacy).
