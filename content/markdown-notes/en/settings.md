Open **Settings** with the gear button in the editor header. You need a note open to reach it. Close it with **Done**.

## Theme

Under **Theme** choose how the app looks:

| Option | Effect |
|---|---|
| **System** | Follows your iPhone or iPad's light or dark mode. |
| **Light** | Always light. |
| **Dark** | Always dark. |

The active option has a checkmark. The change is immediate.

## Accent colour

Under **Accent color** there are eight circles: blue, purple, pink, orange, green, red, cyan and yellow. Tap one to use it. It is the colour of buttons, active icons and folder labels. The default is blue.

## Code theme

The **Code theme** section shows *GitHub* with the text "Code blocks will be highlighted with this theme". Today it is informational only: there is **no selector**, and code blocks use a fixed grey style in the preview, light or dark depending on the device mode.

## Version

Shows the version number. It may not match the App Store one.

## Language

There is no language setting: the app uses Spanish if the device is in Spanish and English otherwise. Change it in iOS settings.

## What cannot be adjusted

Font size, typeface, list order, starting in a specific mode, or turning iCloud on/off: there are no options for these in the app. For iCloud, see [Data and sync](/apps/markdown-notes/docs/data-sync).
