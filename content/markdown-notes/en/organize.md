## The notes list

The sidebar has three blocks:

1. **All Notes**, with the total number of notes.
2. **Folders**, with the number of notes in each and the **New folder** button.
3. The notes list (headed **Notas**, shown in Spanish), sorted by last modified, most recent first.

Each note shows its title (or **Untitled** if empty), its folder in a coloured label, and the first 30 characters of the text.

## Folders

Folders group notes. They are single-level: you cannot nest them, and a note can only be in one folder.

| Action | How |
|---|---|
| Create | **New folder** → type the folder name (field shown as **Nombre de la carpeta**) → **Crear**. |
| See its notes | Tap the folder. Tap **All Notes** to remove the filter. |
| Rename | Long-press the folder → **Rename** → **Guardar**. |
| Delete | Long-press the folder → **Eliminar**, and confirm. |
| Move a note | Long-press the note → **Mover a carpeta** → choose a folder or **No folder**. |

If you create a note or import a file while a folder is selected, the note goes into that folder.

Folders are sorted alphabetically. Empty names are not accepted.

> Deleting a folder does **not** delete its notes: they move to **No folder**, as the confirmation message says. They still appear in **All Notes**.

## Deleting notes

Swipe a note left, or long-press it and choose **Eliminar**.

> There is no trash and no confirmation: the note is deleted instantly. If you use iCloud, the deletion also spreads to your other devices. Before deleting something important, [export it](/apps/markdown-notes/docs/import-export).

## Tags

Tags are words you add to a note. They appear as capsules under the editor header.

1. Open the note and tap ⋯ → **Tags**.
2. Under **Add tag**, type in **New tag** and tap the plus button.
3. Or tap one of the **Suggestions**: work, personal, ideas, project, notes, important. Ones the note already has are not repeated.
4. Tap **Done**.

To remove a tag, tap the x on its capsule in the editor, or the trash icon in the **Tags** sheet.

Tags are always saved in lowercase. You can type your own, not just the suggested ones.

> Today tags only classify each note visually. There is **no filter by tag** and search does **not** look in them. If you want to find a note by a word, also write it in the title or text.

## Search

Type in the sidebar search field (**Buscar notas**, shown in Spanish). It finds notes whose **title or text** contain what you typed, ignoring upper/lower case.

- If a folder is selected, it searches **only inside that folder**. Tap **All Notes** to search everything.
- It filters as you type. To go back to the full list, clear the text.
- It is literal text search: it does not tolerate typos or search by meaning.
