## La lista de notas

La barra lateral tiene tres bloques:

1. **Todas las notas**, con el número total de notas.
2. **Carpetas**, con el número de notas de cada una y el botón **Nueva carpeta**.
3. La lista de notas (encabezado **Notas**), ordenada por última modificación, la más reciente arriba.

Cada nota muestra su título (o **Sin título** si está vacío), la carpeta en una etiqueta de color y los primeros 30 caracteres del texto.

## Carpetas

Las carpetas agrupan notas. Son de un solo nivel: no se pueden anidar, y una nota solo puede estar en una carpeta.

| Acción | Cómo |
|---|---|
| Crear | **Nueva carpeta** → escribe el **Nombre de la carpeta** → **Crear**. |
| Ver sus notas | Toca la carpeta. Toca **Todas las notas** para quitar el filtro. |
| Renombrar | Mantén pulsada la carpeta → **Renombrar** → **Guardar**. |
| Eliminar | Mantén pulsada la carpeta → **Eliminar**, y confirma. |
| Mover una nota | Mantén pulsada la nota → **Mover a carpeta** → elige carpeta o **Sin carpeta**. |

Si creas una nota o importas un archivo mientras tienes una carpeta seleccionada, la nota entra en esa carpeta.

Las carpetas se ordenan alfabéticamente. No se admiten nombres vacíos.

> Al eliminar una carpeta **no se borran sus notas**: pasan a **Sin carpeta**, como dice el aviso de confirmación. Siguen apareciendo en **Todas las notas**.

## Eliminar notas

Desliza una nota hacia la izquierda, o mantenla pulsada y elige **Eliminar**.

> No hay papelera ni confirmación: la nota se borra al instante. Si usas iCloud, el borrado también se propaga a tus otros dispositivos. Antes de borrar algo importante, [expórtalo](/apps/markdown-notes/docs/import-export).

## Etiquetas

Las etiquetas son palabras que añades a una nota. Aparecen como cápsulas bajo la cabecera del editor.

1. Abre la nota y pulsa ⋯ → **Etiquetas**.
2. En **Añadir etiqueta**, escribe en **Nueva etiqueta** y pulsa el botón más.
3. O toca una de las **Sugerencias**: trabajo, personal, ideas, proyecto, notas, importante. Las que ya tiene la nota no se repiten.
4. Pulsa **Hecho**.

Para quitar una etiqueta, toca la x de su cápsula en el editor, o la papelera en la hoja **Etiquetas**.

Las etiquetas se guardan siempre en minúsculas. Puedes escribir las tuyas, no solo las sugeridas.

> Hoy las etiquetas solo sirven para clasificar visualmente cada nota. **No hay filtro por etiqueta** y el buscador **no las busca**. Si quieres poder encontrar una nota por una palabra, escríbela también en el título o el texto.

## Buscar

Escribe en el campo de búsqueda de la barra lateral (**Buscar notas**). Se buscan notas cuyo **título o texto** contengan lo escrito, sin distinguir mayúsculas de minúsculas.

- Si tienes una carpeta seleccionada, se busca **solo dentro de esa carpeta**. Toca **Todas las notas** para buscar en todo.
- Se filtra mientras escribes. Para volver a la lista completa, borra el texto.
- Es una búsqueda de texto literal: no tolera erratas ni busca por significado.
